📖 Giới thiệu môn học

CSE391 – Web Programming là môn học cung cấp kiến thức nền tảng và kỹ năng thực hành về phát triển ứng dụng web hiện đại. Sinh viên sẽ được học cách xây dựng một website hoàn chỉnh, từ giao diện người dùng (Front-end) đến các khái niệm cơ bản phía máy chủ (Back-end).

Môn học không chỉ tập trung vào lý thuyết mà còn chú trọng thực hành, giúp sinh viên làm quen với quy trình phát triển web trong thực tế.

🧠 Nội dung chính của môn học

HTML5 – Xây dựng cấu trúc trang web

CSS3 – Thiết kế giao diện và bố cục

JavaScript cơ bản – Tăng tính tương tác cho website

Responsive Web Design – Thiết kế web tương thích nhiều thiết bị 📱💻

Git & GitHub – Quản lý mã nguồn và làm việc nhóm

Làm quen với Web Server và kiến thức nền tảng về Back-end

Sử dụng một số thư viện / framework hỗ trợ (Bootstrap, v.v.)

🎯 Mục tiêu môn học

Sau khi hoàn thành môn CSE391, sinh viên có thể:

✔ Hiểu cách một website hoạt động từ Front-end đến Back-end cơ bản
✔ Tự xây dựng một website hoàn chỉnh
✔ Áp dụng CSS để tạo giao diện đẹp và thân thiện người dùng
✔ Sử dụng JavaScript để xử lý các tương tác
✔ Biết cách quản lý dự án bằng Git/GitHub
✔ Có tư duy phát triển web phục vụ cho các dự án thực tế

📂 Nội dung Repository

Repository này được tạo để lưu trữ toàn bộ bài tập và sản phẩm trong quá trình học:

📁 html/ – Bài tập và thực hành HTML

📁 css/ – File CSS thiết kế giao diện

📁 js/ – Các bài JavaScript

📁 assets/ – Hình ảnh và tài nguyên sử dụng trong web

📄 README.md – File giới thiệu repository
